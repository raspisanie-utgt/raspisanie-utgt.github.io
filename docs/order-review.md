# Проверка распоряжений

Справочник дисциплин объединяет недельные расписания и периоды `praktika`
из `data/calendar.json`. Календарь содержит ссылку на официальный учебный график.
Для подтверждённых названий учебной практики допускается также общее название
«Учебная практика», использованное в распоряжении №75. Неизвестное уточнение
после этого названия требует проверки, даже если оно похоже на известное.

Если предмет не подтверждён, повторно читаются два фрагмента его ячейки
с разными масштабами, порогами и режимами Tesseract. Принимается только
полное совпадение обоих чтений с записью справочника. Этот способ перенесён
из локальных OCR-наработок. Проверки групп, уроков и кабинетов остаются отдельными.

Повторный проход отдельно проверяет заголовок таблицы. В отчёте перечисляются
расходящиеся строки, поля, исходные чтения и просьба сверить их с фотографией.

На фото №75 режим Tesseract PSM 3 читает номер как 175, а PSM 6 — как 75.
Различие возникает при распознавании изображения. Правила извлечения номера
не добавляют цифру. Диагностика сохраняет оба варианта без автоматического
выбора. Номер не служит ключом публикации, ключом является дата занятий.

Первичное чтение №75 после исправления справочника подтверждает все 15 строк,
включая шесть отмен и две строки практики. Повторное чтение в локальном Windows
окружении оставляет сомнения по другим предметам. Такой документ продолжает
требовать проверки. Устранение причины ложного предупреждения не гарантирует
автоматическую публикацию всего документа.

Вывод OCR декодируется как UTF-8. Список языков в тесте проверяется по байтам,
поскольку Windows Tesseract может вывести путь к языковым данным в системной
кодировке. Проверка уверенности архивного снимка 19.10.2026 сохранена.

Рабочие сервисы обновляются только после согласования. OpenRouter использует
режим `suggest`. Результаты повторного OCR проверяются до публикации.
