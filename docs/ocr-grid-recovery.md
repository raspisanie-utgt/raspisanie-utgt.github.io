# Восстановление сетки и даты в OCR

## Изменение

Если сетка исходного снимка читается, он остаётся без преобразований. Только при
ненайденной сетке проверяются контраст и небольшие повороты до 3 градусов.
Восстановленный вариант должен содержать пять вертикальных границ и не обрезать
продолжающиеся линии таблицы снизу. Заголовок дополнительно определяется по
совместному наличию слов о дисциплине, аудитории и группе/уроке. Новых зависимостей нет.

Для повернутого изображения координаты обрезки не переносятся на исходную
фотографию: сайт сохраняет целое изображение. Исходные файлы не изменяются.

Если дата занятий в шапке не прочиталась, увеличенная выровненная шапка читается
режимами PSM 6 и 11. Новый результат принимается при совпадении двух дат после
«на». Противоречащие даты не выбираются произвольно. Дата подписания не заменяет
утраченную дату занятий в этом дополнительном проходе.

У известных пар аудиторий нормализуются только пробелы вокруг `/`.
Неизвестные номера и отсутствующие разделители не исправляются догадкой.
Составные предметы разделяются по `/` вне скобок и проверяются по частям;
неподтверждённая часть не отбрасывается. Запись двух языков в одних скобках
раскрывается только при точном наличии обоих названий в справочнике.
Все прежние проверки строк, диапазонов, групп, предметов и независимого OCR сохранены.

## Генерируемые проверки

`tools/generate_vk_ocr_cases.py` создаёт изображения и эталонные строки отдельно
от `data/`. Набор помечается `SYNTHETIC_ONLY`; автоматического импорта в рабочие
данные нет. `--stress` добавляет последовательные отмены без аудиторий, практику
1–6, длинную дисциплину с диапазоном 5–10 и неизвестный предмет, который обязан
остаться на проверке.
`--compound` дополнительно проверяет «немецкий / Химия» и две языковые подгруппы.

Полная формулировка длинной дисциплины в стресс-снимке имеет явный эталон из
справочника: «…микропроц. и диагност. систем автоматики». Эталон не выводится
автоматически через нечёткое сравнение. Иначе корректное сокращение ошибочно
считалось бы неправильной строкой в тесте.

Пример отдельного тестового набора:

```sh
python tools/generate_vk_ocr_cases.py _proverka/stress --font /path/to/font.ttf --count 70 --stress
python tools/benchmark_vk_ocr_cases.py _proverka/stress --variant candidate=. --data-root data
```

Для сравнения двух вариантов передаются два `--variant NAME=PATH` и общий
`--data-root`. Эталонные строки не передаются распознавателю. Обновление сайта,
нейросеть и ручные поправки в этом тестировании отключены. Успешный ответ при
неправильной строке, дате, пропуске либо обязательной ручной проверке считается
небезопасным допуском. Низкая точность тяжёлого снимка сама по себе не разрешает публикацию.

На Windows доступен ускоренный прогон через `--library` и `--tessdata` для
локальной библиотеки Tesseract. Его результаты сравниваются только в одинаковом
окружении; интеграционные тесты отдельно используют настоящий процесс Tesseract.
