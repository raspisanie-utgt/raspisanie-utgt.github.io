## Следующие задачи

1. ВК: проверить `wall.get` с официальным сервисным ключом разрешённого приложения. Без ключа API возвращает «Access denied: token required». После проверки сделать запрос ВК независимым от страницы новостей техникума. При отказе источника сохранять предыдущую ленту.
2. Распознавание: собрать обезличенные результаты двух моделей и ручную разметку нескольких распоряжений. Сравнить полноту строк, диапазоны уроков, отмены, кабинеты и длинные названия. Оригиналы хранить без изменений, спорные чтения оставлять в `suggest`. В пробе Tesseract.js от 11 ноября точных совпадений с сохранёнными строками было 2 из 7 для 3 ноября, 0 из 21 для 5 ноября и 25 из 31 для 11 ноября. На №69 ошибались диапазоны, отмены и кабинет. Вариант с автоконтрастом и изменением отступов не нашёл таблицу на №69. Сохранённых ответов OpenRouter для оценки моделей пока нет.
3. Обратная связь: в выборке из 12 плановых запусков GitHub Actions интервалы были 39–80 минут при настройке опроса раз в 15 минут. Сами запуски занимали 10–14 секунд. После включения метрики измерить фактическое ожидание сообщений. Проверить повтор после сбоя между созданием задачи и подтверждением сообщения. Сохранить текущий опрос до отдельного решения по инфраструктуре.
4. Данные: сверить две фамилии преподавателей с актуальным официальным списком, когда он станет доступен. Уточнения по кабинету и кураторам остаются в CLAUDE.md. Новые официальные адреса проверять по подтверждённым источникам.

Идеи, зависящие от решения администрации, сохраняются в CLAUDE.md: домашние задания от преподавателей, листы с кодом для телефона, адрес на домене техникума и доступ к новостям ВК.
